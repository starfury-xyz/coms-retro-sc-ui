# What does this do?
This attempts to give the retro feeling of Star Conflict without jumbling **too much** of the UI around.
In other words, it's shameless nostalgia bait that's familiar enough to where you can still play the game without massively questioning your life choices.

# Features:
- Reduced number of concurrently visible items in each drop down
- Brought back old sprites
- Moved the position of the ships to the left
- Moved the weapon, ammo, special module, and active modules to the bottom of the screen where the ships were
- Moved the passive modules on top of the weapons+abilities, and completely reorganized them to be horizontally laid instead of vertically laid
- Centered the text for the passive module slot type categories
- Added logic so the passive modules center within each group
- Added logic so that when there are missing categories of passive modules, the whole element centers itself accordingly instead of just being right-aligned
- Removed the seed chip editor (If you would like it back, simply remove the "negative" sign on the file `graphics/equip_1080/equip_main2.sanim` on line 273, so that the line reads `pos 17 799` and not `pos 17 -799`

# And everyone's favorite,
- Reverted quite a few old icons, but not all of them- this pack maps all the common ones, but only about 450 of the 700 total mappings of items are redone, and I have refused to touch some alien ones that i'm not so sure of.
- Took some *creative liberties in deciding which new modules should map to what old icons, some unused, some reused. I'm aware this might get confusing.*
